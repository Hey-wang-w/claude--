笔记 · 自来水厂

  1. 沉淀 → 过滤 → 吸附 → 消毒
  2. 絮凝剂（如明矾）：使悬浮杂质沉降
  3. 活性炭：吸附色素和异味
  4. 投药消毒：杀灭细菌 → 化学变化
  5. 自来水仍含可溶性杂质 → 是混合物

笔记 · 沉降

  1. 静置沉淀：除去较大的不溶性颗粒
  2. 明矾溶于水生成胶状物，吸附悬浮杂质，使其沉降
  3. 明矾不能杀菌消毒，也不能除去可溶性杂质

    1. 一贴：滤纸紧贴漏斗内壁

    笔记 · 过滤总结

    1. 一贴二低三靠，玻璃棒引流
    2. 滤液浑浊：滤纸破损、液面高于滤纸边缘、仪器不干净 → 查明原因，重新过滤
    3. 过滤太慢：滤纸没紧贴、有气泡；泥沙多 → 先静置再过滤
    4. 过滤后的水仍含可溶性杂质

    笔记 · 吸附与消毒

    1. 活性炭疏松多孔，有吸附性：除去色素和异味 → 物理变化
    2. 投药消毒（如二氧化氯）杀灭细菌 → 化学变化
    3. 生活中常用煮沸的方法杀菌

    实验 · 制取蒸馏水

    蒸馏：净化程度最高的方法

    温度计 20 ℃收集蒸馏水 0.0 mL冷凝水 未通

    实验记录

      按 ①→⑥ 操作。

      笔记 · 蒸馏

      1. 加沸石（或碎瓷片）：防止暴沸
      2. 冷凝管中冷水下进上出；先通冷凝水，再加热
      3. 弃去开始馏出的液体（含杂质）
      4. 蒸馏水是纯净物；净化程度：沉降 < 过滤 < 吸附 < 蒸馏

      认识 · 硬水与软水

      用肥皂水区分硬水和软水

      判断一下 红队答题

      振荡后，哪支试管里是硬水？

      先滴肥皂水、振荡，再观察判断

      笔记 · 硬水与软水

      1. 硬水：含较多可溶性钙、镁化合物
      2. 软水：不含或含较少可溶性钙、镁化合物
      3. 加肥皂水振荡：泡沫多、浮渣少 → 软水；泡沫少、浮渣多 → 硬水
      4. 过滤、吸附不能除去钙镁化合物 → 自来水不一定是软水
