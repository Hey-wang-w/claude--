笔记 · 自来水厂

  1. 沉淀 → 过滤 → 吸附 → 消毒
  2. 絮凝剂（如明矾）：使悬浮杂质沉降
  3. 活性炭：吸附色素和异味
  4. 投药消毒：杀灭细菌 → 化学变化
  5. 自来水仍含可溶性杂质 → 是混合物

易错自来水是混合物，也不一定是软水。

笔记 · 沉降

  1. 静置沉淀：除去较大的不溶性颗粒
  2. 明矾溶于水生成胶状物，吸附悬浮杂质，使其沉降
  3. 明矾不能杀菌消毒，也不能除去可溶性杂质

易错明矾能使杂质沉降，但不能杀菌消毒。

笔记 · 过滤

  1. 过滤：把不溶性固体与液体分离
  2. 器材：铁架台（带铁圈）、漏斗、滤纸、烧杯、玻璃棒
  3. 玻璃棒的作用：引流

易错过滤只除不溶性杂质，食盐水过滤后仍是食盐水。

    笔记 · 过滤操作

    1. 一贴：滤纸紧贴漏斗内壁
    2. 二低：滤纸边缘低于漏斗边缘；液面低于滤纸边缘
    3. 三靠：烧杯口靠玻璃棒；玻璃棒靠三层滤纸；漏斗下端靠烧杯内壁

    易错不能用玻璃棒在漏斗里搅拌，会戳破滤纸。

    笔记 · 过滤总结

    1. 一贴二低三靠，玻璃棒引流
    2. 滤液浑浊：滤纸破损、液面高于滤纸边缘、仪器不干净 → 查明原因，重新过滤
    3. 过滤太慢：滤纸没紧贴、有气泡；泥沙多 → 先静置再过滤
    4. 过滤后的水仍含可溶性杂质

    易错过滤后澄清的水仍不是纯水。

    观察 · 活性炭

    活性炭为什么能“吸”走颜色？

    笔记 · 吸附与消毒

    1. 活性炭疏松多孔，有吸附性：除去色素和异味 → 物理变化
    2. 投药消毒（如二氧化氯）杀灭细菌 → 化学变化
    3. 生活中常用煮沸的方法杀菌

    易错活性炭不能杀菌，也不能把硬水变成软水。

    设计 · 简易净水器

    用塑料瓶做一个净水器

    从瓶底往上依次装填 红队答题

    瓶口朝下，水从上往下流。正确 +5 分

    笔记 · 简易净水器

    1. 自上而下：小卵石 → 石英砂 → 活性炭 → 蓬松棉
    2. 先粗后细：卵石、石英砂起过滤作用；活性炭吸附
    3. 得到的水仍含可溶性杂质，不是纯水

    易错得到的水不能直接饮用，还需消毒。

    实验 · 制取蒸馏水

    蒸馏：净化程度最高的方法

    实验记录

    温度计 20 ℃收集蒸馏水 0.0 mL冷凝水 未通
      可以点下方按钮，也可以直接拖动、点击仪器。

      笔记 · 蒸馏

      1. 加沸石（或碎瓷片）：防止暴沸
      2. 冷凝管中冷水下进上出；先通冷凝水，再加热
      3. 弃去开始馏出的液体（含杂质）
      4. 蒸馏水是纯净物；净化程度：沉降 < 过滤 < 吸附 < 蒸馏

      易错温度计水银球在支管口处，不插入液体。

      认识 · 硬水与软水

      用肥皂水区分硬水和软水

      判断一下 红队答题

      振荡后，哪支试管里是硬水？

      先滴肥皂水、振荡，再观察判断

      笔记 · 硬水与软水

      1. 硬水：含较多可溶性钙、镁化合物
      2. 软水：不含或含较少可溶性钙、镁化合物
      3. 加肥皂水振荡：泡沫多、浮渣少 → 软水；泡沫少、浮渣多 → 硬水
      4. 过滤、吸附不能除去钙镁化合物 → 自来水不一定是软水

      易错澄清透明的水也可能是硬水。
