# 实验装置画法与核对表

老师对实验装置非常敏感，最近八轮反馈里一半是装置问题：位置关系、方向、颜色、因果顺序。原则：**照教材插图画，画完逐项核对，再用动画验证过程。**

## 1. 通用原则

- **先找插图**：画任何装置前，先找最新人教版教材的插图，或请老师发图（聊天里的截图可以直接看）。不要凭印象画——“试管插在冷水烧杯里”的简易蒸馏装置就是凭印象画错的，教材用的是冷凝管。
- **主体仪器要画得足够大**：要让学生看清细节（滤纸层数、液面位置），必要时只画局部或加放大镜。
- **逼真**：玻璃用半透明填充 + 描边 + 高光条；金属用渐变；液体画出液面反光线；容器里有溶液就必须画出液体。
- **按真实比例**：数量对比（例如 100 L 水里只有 0.77 L 可利用）按比例画，再用镜头推近或放大镜看细节。

## 2. 空间关系核对表

画完每个装置，逐项回答“是 / 否”，有一项不对就改：

- **谁放在谁上面**：仪器底部是否正好落在支撑面上？（酒精灯在铁架台底座铁板上，烧杯在底座上，烧瓶在陶土网上，漏斗卡在铁圈上——都不能悬空，也不能嵌进去。）
- **谁贴着谁**：该紧靠的地方是否真的接触？（漏斗下端尖嘴的长边紧靠烧杯内壁；烧杯嘴靠玻璃棒；玻璃棒下端靠三层滤纸。）
- **谁伸进谁里面**：伸入的部分是否在正确的一侧？（玻璃棒压滤纸时在滤纸**内表面**，不能插进滤纸与漏斗壁之间；漏斗颈要伸进烧杯口以下；牛角管要伸进锥形瓶口。）
- **方向**：倾斜方向、水流方向、气流方向是否和插图一致？（倾倒时玻璃棒从左上斜向右下，烧杯在右上方；冷凝水下进上出。）
- **大小匹配**：铁圈直径与漏斗锥体是否匹配（铁圈太大，漏斗就会掉下去）？夹子是否夹在瓶颈上？
- **加热位置**：外焰是否正好接触陶土网或容器底部？

## 3. 过滤

- 器材：铁架台（带铁圈）、漏斗、滤纸、烧杯（两个）、玻璃棒。
- **一贴**：滤纸紧贴漏斗内壁，中间不留气泡；润湿后**用玻璃棒**轻压赶走气泡（不能用手指），棒尖压在滤纸内表面。
- **二低**：滤纸边缘低于漏斗边缘；液面低于滤纸边缘。画标注时把“漏斗边缘 / 滤纸边缘 / 液面”三条线错开，文字不能叠在一起。
- **三靠**：烧杯嘴紧靠玻璃棒；玻璃棒下端轻靠**三层滤纸**一侧；漏斗下端尖嘴的长边紧靠烧杯内壁（承接烧杯放在漏斗正下方偏一侧，使尖嘴贴住内壁）。
- **滤纸**：折法是对折、再对折、打开成圆锥，一侧一层、一侧三层。**一层和三层要有明显色差**：一层半透明，三层更深、不透明，并画出层边线。
- 结果：滤纸上留下泥沙，滤液澄清；若仍浑浊，查明原因后再过滤。

## 4. 蒸馏（冷凝管装置，教材实验）

- 组成：带支管的圆底烧瓶（放在陶土网上，用铁夹夹住瓶颈）、温度计（**水银球在支管口处**）、冷凝管（用第二个铁架台夹住）、牛角管、锥形瓶；酒精灯在左侧铁架台底座上。
- **冷凝管**：玻璃外套两端收口，内管贯穿；进出水口是带接头的小管，接橡胶管。**冷水下口进、上口出**，用三种方式表现：外套里的冷水、管内流动箭头（自检时确认动画方向，曾经画反）、管外进水和出水箭头。
- 沸石（或碎瓷片）防暴沸；**不加沸石时演示暴沸**；液体热时不能补加沸石。
- **先通冷凝水，再加热**；不通冷凝水时，水蒸气从锥形瓶口逸出，几乎收集不到水。
- 开始馏出的液体要**弃去**（可能含易挥发的杂质）；**馏出液画成无色透明**，用文字标注“初馏液 · 应弃去”，不要用颜色区分。
- 结束：用灯帽盖灭酒精灯，稍后再停止通冷凝水。烧瓶里剩下的水杂质更多（可以略带黄色调）。

## 5. 加热与铁架台

- 酒精灯放在铁架台底座铁板上（灯底与铁板上表面平齐），用外焰加热；熄灭用灯帽盖灭（画出灯帽）。
- 烧瓶、烧杯加热要垫陶土网（新教材用“陶土网”，不再叫“石棉网”）。
- 铁夹、铁圈从立杆伸出，连接处画出夹持块；立杆在底座上。

## 6. 流程动画（以自来水厂为例）

- **装置画在它作用的位置**：絮凝剂加在进入沉淀池之前的进水管上；消毒剂加在清水池**上方**，滴进池水里。
- **先后顺序符合因果**：滴入 → 扩散（颜色晕开）→ 产生结果（细菌变灰、打叉、消失）。清单、计分、文字说明都要等结果出现之后再更新。
- 给学生一个持续可见的“状态清单”（例如“水里还剩哪些杂质？”逐站划掉，最后钙镁化合物“仍存在”），把抽象的流程变成看得见的变化。
- 每一站都可以直接点击跳转，不必只能逐站点“下一站”。

## 7. 微观粒子与杂质的统一画法

同一套课件里，同一种东西始终用同一种画法（`assets/lab-draw.js`）：

| 东西 | 画法 |
|---|---|
| 泥沙等不溶性杂质 | 不规则多边形颗粒，带明暗和描边（`grain`） |
| 细菌等微生物 | 杆菌 + 波动的鞭毛（`bacterium`），死亡时变灰并打叉 |
| 色素分子 | 琥珀色三联环（`pigmentMol`），水体同时带黄色调 |
| 异味分子 | 紫色圆点 + 向上飘的气味线（`odorMol`） |
| 钙、镁离子 | 蓝色小球标“2+”或“Ca²⁺ / Mg²⁺”（`ionDot`） |

画面上要配图例，或者用清单的图标兼作图例。

## 8. 错误状态怎么画才“一眼能看出”

找茬题、故障诊断里的错误状态，要让学生不借助标注也能看出来：

- 液面高于滤纸边缘：液面升到接近漏斗口，透过液体能看到被淹没的滤纸边缘（白色圈），浑水从滤纸和漏斗壁之间的缝隙流下，承接烧杯里的滤液明显变浑。
- 没用玻璃棒引流：液体从烧杯直接冲进漏斗，有溅起的液滴。
- 漏斗下端没靠烧杯内壁：液滴从尖嘴悬空滴落，溅起涟漪。
- 判定区域覆盖整片出错的地方（见 `framework.md` 第 5 节）。

## 氢气验纯（第四单元复习反馈）

- 用拇指堵住集满氢气的试管口，**管口斜向下**（不是竖直向下）靠近酒精灯火焰，移开拇指点火。
- 尖锐爆鸣声 → 不纯；声音很小（“噗”）→ 较纯。动画里先移开拇指，再出现爆鸣或“噗”。

## 第一单元复习的实物核对（老师反馈）

- **燃烧匙**：照课本图 1-9 实物——一根长铁杆，下端弯折，末端是一个匙口朝上的小匙；没有横柄、没有圆盘。
- **试管夹**：木制，长柄在前、短柄在后，两片木条中部由钢丝弹簧夹住（钢丝在柄上绕成弹簧圈）；前端夹口有半圆槽夹住试管；全长约 18 cm、宽约 1.5 cm。夹在距管口约 1/3 处，从试管底部往上套。**夹口没有金属环**。
- **镊子**：两片不锈钢片在尾部焊在一起，前端收窄成尖，中部有防滑纹。
- **手**：能省略就不画；必须画时与仪器同一真实比例（手指粗约 1.7 cm、长 7～10 cm）。手指绕过的角度 ≈ 指长 ÷（仪器半径 + 半个指粗）：试管（直径 1.8 cm）能握拢、拇指压在食指上；试剂瓶（直径 5 cm 以上）握不拢、指尖停在瓶身正面、拇指在瓶后。画法与仪器一致（2D 扁平），不要 3D 渲染的手。
- **倾倒液体**：瓶塞倒放、标签朝向手心、瓶口紧挨试管口；倾倒时手从上方握住瓶身（手心贴着标签一侧），残液沿瓶口下沿流下。
- **危险化学品标志**：用课本图 1-11 原图（GB 190—2009），共 6 个：爆炸性物质、易燃气体、易燃固体、易于自燃的物质、毒性物质、腐蚀性物质。
