# 风格、游戏、互动方式参考库

规划一套新课件时，从这里挑选组合，并在动手前给老师一个简短的“推荐方案 + 1～2 个备选”（她通常会说“开始做吧”，也可能指定风格）。选择规则：

- **视觉风格**：不与最近两套课件相同（她明确要求避免连续几期相似、审美疲劳）。复习课可以沿用她点名喜欢的风格。
- **最终竞赛**：不与最近三套课件相同；Boss 形象绝不跨课复用。
- **互动方式**：一套课件里至少用 4 种不同的作答方式，再加 1～2 个“哇”时刻（震撼演示）。
- “已用”一栏写明用在哪套课件里，查 `style-history.md` 可以看到更多细节。

## 四、互动方式库

演示类：
- 2D 画布动画（分子运动、扩散、溶解）；3D 可旋转模型或沙盘；放大镜看微观粒子；按真实比例呈现并配合运镜。
- 虚拟实验：滴加、加热、计时、颜色渐变，以及“教材装置 / 改进装置”切换（如 T 形管）。
- 参数滑块计算器：改参数出新题，先算后揭晓。

作答类：
- 选择、判断（附理由）、多选（分别标出漏选 / 多选）、填表（检查 / 显示答案 / 重做）、拖拽分类、排序、连线配对、画图、在图上点选位置、计算输入。

课堂组织类：
- 红蓝队轮答（自动换队）、抢答（两队各用一个键盘按键）、随机点名、计时器、教师可选题量、目录里手动调分。

总结类：
- 易错便利贴（学生点“我会了”）、知识卡收集册、思维导图逐枝揭晓、承诺打卡（点亮后填满水瓶）、下节课预告。

## 五、“哇”时刻清单（每套课件 1～2 个）

- 粒子爆炸重组、电子跃迁的辉光轨迹（微观主题）。
- 真实比例的镜头推拉对比（100 L 对 0.77 L）。
- 3D 沙盘因果链（治理后河水变清、鱼游回来）。
- 封面可交互（3D 地球投点、拖动形成水面涟漪）。
- 竞赛结局特效（Boss 碎裂、火箭发射、礼花）。
