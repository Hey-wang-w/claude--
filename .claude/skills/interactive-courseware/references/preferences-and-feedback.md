# 需求与纠正记录（按课件顺序）

记录每套课件的原始需求、老师后来指出的问题和我们的修正方式。读这份文件的目的是**提前避开同类问题**。“⚠”标出的是重复出现、最该警惕的问题。

## 0. 高频教训清单（从下面各套课件的记录中提炼，动手前和交付前各对照一遍）

括号里是出处（第几节）。

**内容**
- 不超纲；练习册只定范围和题型，不用原题；单元、课题编号以练习册为准（1、2、6）。
- 重难点笔记做成页眉“笔记”按钮弹出，不占版面；老师根据学情板书（11）；笔记要配图，不只写文字（12）。
- ⚠ 老师要知名游戏 / 动漫角色时，说明版权问题，改做同类画风的原创角色（14）。
- ⚠ 风格选择时深色系（霓虹、街机夜景）要谨慎；老师否定过像素街机的深紫霓虹配色，最稳的是浅色方格纸 + 贴纸（14）。
- ⚠ 每页文字要少，能删的说明全部删掉（11）；但**概念定义不能删成短语**，“纯净物”“化合物”这类属概念必须保留（11）。
- 可溶性的、看不见的东西（色素、异味、钙镁离子）也要可视化，并持续追踪到底（8）。
- 未揭晓的答案不能用随机数字“滚动”占位，学生会当成真实数据；显示“??”（13）。
- 计算课的数据要凑整，心算加草稿能完成；相对原子质量按教材附录取整（13）。
- 讲解例子与学生练习分开：例子放选项卡最前（标“例”），舞台和笔记里的例子不能与练习同题同数（13）。
- 练习对应的计算结果、推理过程都先盖住，点一次揭晓一步，不自动播放（13）。
- 比值不化简也判对，提示看题目要求；小数多的计算给计算器（13）。

**答题与互动**
- 先作答、再提交判分；错了不加分；不能用“拦截错误”代替判分（2）。
- 错误提交也必须能提交，提交后展示正确答案（2）。
- 有顺序的知识要检查顺序（2）。
- 找茬按区域判定，一整片出错的地方点哪里都算对（8）。
- 虚拟实验要让错误发生并展示后果；除了按钮，还要能直接拖动、点击仪器（8）。
- 老师要能选择全做或部分做、计时、重来（2）。

**题目与配图**
- 包含关系图：单质与化合物**并列、不相交**，氧化物完全在化合物里；全课同类图一起检查（11）。
- 旋转摆放的元素（拍立得、胶带）边缘不能有锯齿（11）。
- 题干提到的图必须真的有、能显示（2、5）。
- 图例和示意图同色同形；箭头、文字随画面一起缩放（5）。
- 粒子要大到能数清（3）。

**实验装置与动画**（详见 `lab-apparatus.md`）
- 照教材插图画：蒸馏用冷凝管装置，不用简易装置（8）。
- 空间关系逐项核对：漏斗卡在铁圈上，尖嘴长边靠烧杯内壁，玻璃棒压滤纸内表面，酒精灯在底座铁板上（8）。
- 方向和顺序要对：倾倒时玻璃棒从左上斜向右下，冷凝水下进上出；加药装置在它作用的池子上方，先滴入、再扩散、后出结果（8）。
- 颜色不能误导：馏出液是无色的（8）；一层和三层滤纸要有色差（8）。
- 装溶液的容器要画出液体，装置要逼真（5）；错误状态要一眼能看出（8）。
- 物理逻辑正确：冰浮在水上（6）。

**视觉与版式**
- 全课只用站酷快乐体 + 思源黑体两种字体（8）。
- 舞台操作按钮统一放在底部中间工具栏，纯文字（8）。
- 版式整洁，线条横平竖直、不交叉，可参照教材原图布局（5、6）。
- 配色要高级，素材要精致（6）；图标用代码画，标志与官方一致（6）。
- 固定画布 + 整体缩放，任何屏幕布局一致（6）。
- 画布里的主体要按画布大小铺开，不能缩在一角留下大片空白（13）。
- 风格由老师选，可以沿用；竞赛、游戏每套换新；Boss 不跨课复用（3、4、8）。

**3D**（只在老师要求时做，见 `3d-playbook.md`）
- 用 Blender 建模，不用基本几何体拼凑；按真实比例，镜头推近看细节；模型贴地、无闪烁、光晕完整（6、7）。
- 老师要“精美游戏素材”时，可以把 CC0 带骨骼角色在 Blender 里摆姿势、渲染成 2D 精灵动画放进画布（13）。

**工作方式**
- 提交后立即判分；延时动画用题号令牌作废，防止换题后串题（12）。
- 老师指出一个问题，就系统排查全课的同类问题（2）。
- 老师说“按你的理解优化”时，主动做一轮全课打磨，并说明改了什么（8）。
- 风格以老师最后的指定为准，开工前确认（5）。

## 2. 原子结构示意图与离子（`ion-structure/`，深色霓虹风，15 页）

- 需求：动画更炫酷夸张、游戏更精美、互动更丰富；包括钾、钙（第 4 层）；离子部分提一下原子团；只在一块大屏上用、全班一起互动；**按同样的题型另外出题**；45 分钟。
- 老师先让我分析需求、提建议，再说“开始做吧”。老师喜欢有建设性的建议，例如“你的几点建议还不错，先按照你的建议完成”。
- 反馈与修正：
  - “加一项任务：画一画钠、镁、铝等 6 种离子的结构示意图，**教师可以选择全画或部分画**”→ 加任务页、勾选范围、计时器。
  - ⚠ “排布电子时有错误阻止，也就意味学生怎么做都是对的，改成**填完之后点击确认再判断对错，错了不加分**。”
  - 接着又发现：“**错误答案无法提交**”→ 提交错误后本关结束，自动展示正确排布，可重练。
  - ⚠ “我先排的最外层，后排的第一层，只要数字对上了也算对，**加上顺序判断，应该从内向外依次排列**。”→ 记录放置历史，按层检查顺序。
  - “判断错误后示意图部分丢失”→ CSS 动画相互覆盖（错误高亮的动画覆盖了弧线的绘制动画），改为分别作用于不同元素。
  - 总结规律要写全：同一列最外层电子数相同；同一行电子层数相同，最外层电子数依次增加。
  - ⚠ “这题没有图”“题干说‘该原子’却没看到图”→ 题目配图用内联 SVG 时要给出明确的宽高；**每道提到图的题都要检查图是否显示**。
  - ⚠ 老师要求“**系统性梳理整个课件，排查能发现的所有问题或潜在问题**”。修完一个问题后，要主动扫描全课件里的同类问题。

## 6. 水资源及其利用（`water/`，深海玻璃风 + three.js 3D，10 页）

- 需求：“根据 PDF 题目涵盖范围（不足的部分你来补充，**不要用 PDF 中的原题，这是学生家作**），按照最新教材制作。”老师说“第三单元”，但练习册写的是“第四单元 自然界的水”，以练习册为准并向老师说明。
- 第一版（浅蓝“水波玻璃”风、2D 画布）收到的反馈：
  1. ⚠ “课件布局不够整洁”
  2. ⚠ “素材太简陋，要设计得更精致，可以在网上搜集合理的精美素材”
  3. ⚠ “动效要真实，特效要炫酷，能引起学生注意”
  4. ⚠ “配色设计虽然符合主题，但是不够高级和精美”
  5. ⚠ “**重难点在讲解页面就要给出笔记**”
  6. “先进行相关设计的调研，再完善课件”
- 第二版用了 Microsoft Fluent 3D 表情图标：老师回复“**我不是很喜欢这种风格**，课件中的场景演示最好给我 3D 模型，可以操作互动。**图标你自己根据课件风格用代码设计**，精致、符合主题就行。”
- 第三版（three.js 3D）收到的反馈：
  - ⚠ “**图标不对，搜网图核对再设计**”（可回收物标志画错，节水标志不像）。
  - ⚠ “3D 模型都做了，就要做好，**有难度的就直接使用免费 3D 模型库中的模型**，像课件中的猪、水龙头质量都不太好。”
  - ⚠ “这个界面**直接使用实际比例**，倒进小杯子时，**采用镜头放大的效果聚焦小杯**，让学生直观感受（专业细节，你来把控）。”
  - ⚠ “屏幕适应有偏差”→ 改为固定画布、整体缩放。
  - “节水标志还是不对，那些标志你直接用风格一致的网图吧”，并发来官方节水标志原图 → 按原图描画。上传的图片不一定能在文件系统里读到，必要时请老师发文件。
- 第四版的细节反馈（“3D 模型的细节完善一下”）：
  - 水箱底部出现放射状条纹（扇形三角面上的阴影瑕疵）→ 设置阴影的 `normalBias`，并隐藏水柱的底面圆片。
  - 水循环沙盘：海水正面出现一条亮缝（透明面重叠）；从侧面看，地形像一张悬空的薄片 → 地形四周加“侧壁”，海水体积做成不透明。
  - 农田方块悬空、拖拉机浮在空中 → 农田直接画在地形顶点颜色上，模型贴地放置。
  - 地球光晕被方形画布裁切、海面出现两个白色高光 → 镜头拉远，让光晕完整落在画面内；降低环境反射，只保留一个太阳高光。
  - 物理逻辑：冰不能沉在水底、上面还压着液态水 → 改为先倒出可利用的水，剩下的部分原地“冻结”。
- ⚠ 老师的整体评价：“**感觉今天的课件的设计和风格没有第三单元的完美，可能 3D 能力还存在欠缺。**”启示：
  - 3D 不是越多越好。只有 3D 确实能帮助理解（空间结构、真实比例、沙盘因果）时才用，而且必须打磨到不比 2D 页面粗糙。
  - 第三单元那几套（尤其是浅色贴纸风的元素符号课和复习课）的完成度是标杆：信息密度适中、对齐严谨、交互反馈清晰、每页都有明确的学生动作。

## 8. 水的净化（`purify/`，实验记录本风，13 页）

- 需求：参考练习册范围，不用原题；硬水软水只简单认识、不讲转化；过滤由个别学生上台演示（泥沙水），引导 + 操作 + 总结约 10 分钟；蒸馏做成逼真的 HTML 互动实验；不要实验记录单。
- ⚠ **仪器空间关系必须照教材插图核对**：过滤装置里漏斗要卡在铁圈上（铁圈不能比锥体大而让漏斗悬空）；承接烧杯放在漏斗正下方，漏斗下端**尖嘴长边**紧靠烧杯内壁；玻璃棒下端靠三层滤纸，烧杯嘴靠玻璃棒。
- ⚠ **蒸馏要用教材的冷凝管装置**：带支管的圆底烧瓶 + 温度计（水银球在支管口处）+ 冷凝管（冷水下进上出）+ 牛角管 + 锥形瓶，两个铁架台；不要用“试管插在冷水烧杯里”的简易装置。画实验装置前先请老师确认或参照最新教材插图。
- ⚠ 第二轮反馈：微生物、泥沙等**要画得形象**（杆菌 + 鞭毛、不规则带明暗的颗粒，并配图例），不能只是色块；润湿滤纸要**用玻璃棒轻压**赶气泡，不能用手指；倾倒时**玻璃棒从左上斜向右下**，下端靠三层滤纸，烧杯在右上方、杯嘴靠玻璃棒上部；“液面高于滤纸边缘”这类错误状态要**一眼能看出**（液面接近漏斗口、透出被淹没的滤纸边缘、缝隙里浑水流下、滤液变浑），主体仪器（漏斗）要画得足够大。
- ⚠ 第三轮反馈：冷凝管要**逼真**（玻璃外套两端收口、内管贯穿、带接头的进出水小管、橡胶管），并用管内流动箭头 + 管外箭头**清楚表现冷水下进上出**（自检时核对动画方向，曾经画反）；小结页出现画布与表格**重叠**——全局 `.stage>canvas{position:absolute;inset:0}` 会作用到舞台里的任何直接子画布，正常排版的画布要加 `position:relative;inset:auto` 或包一层 div。
- ⚠ 第四轮反馈：**可溶性杂质也要可视化**（色素、异味分子、钙镁离子，统一画法贯穿全课，自来水厂加“剩余杂质清单”逐站划掉，最后钙镁化合物“仍存在”）；**一层 / 三层滤纸要有明显色差**（三层更深、不透明并画出层边）。老师说“模型开高了性能，按你的理解优化”——这类开放要求要主动做一轮全课打磨（填补空白区域、初始状态给操作引导、笔记底部加“易错”提示），并说明改了什么。
- ⚠ 第五轮反馈：**找茬的判定区域要覆盖整片出错的地方**（液面高于滤纸边缘是一整圈，点左边、中间、右边都应判对），不能只认一个点；用区域函数判定，点到别处仍判“这里没错”。**颜色不能带来科学误导**：蒸馏出的初馏液也是无色透明的，不能用绿色区分，靠文字标注说明“应弃去”。
- ⚠ 第六轮反馈：**流程动画的因果和位置要对**——消毒剂装置画在清水池后面（滴进出水管），清水池里的细菌却先死了。加药要画在它作用的池子上方，并按“滴入 → 扩散 → 细菌死亡”的时间顺序演示，清单划掉也要等结果出现之后。

## 10. 化学式（`formula/`，浅色方格纸 + 贴纸，10 页）

- 需求：参考练习册范围、不用原题；外观和特效要精美炫酷、互动方式丰富；教室大屏能触控。
- 老师的决定：K₂MnO₄、Fe₃O₄ 这类化学式给出名称和组成，让学生按读法规则书写，常见的列进“需要记住的化学式”；把离子符号（Mg²⁺、O²⁻）也放进“数字的意义”对比；**不要笔记卡**（“笔记内容不用你做来展示，我会根据学情进行板书”）；风格沿用浅色贴纸；竞赛用化学式宾果。
- 不超纲：本课时不讲化合价，宾果和诊所的题目都避开化合价；数字位置只比较单个原子形成的离子。
- ⚠ 第一轮反馈（选项要唯一、可判）：书写诊所里“氧化物中氧元素应写在右边”是正确项，但干扰项“应写成 C₂O”也是氧在右边，学生会觉得两个都对。老师建议正确项**直接给出正确写法**。做法：每个选项都写成“病因 + 写出的化学式”，干扰项各自写出一个错误的化学式，保证只有一个选项能得到正确答案；出题后逐个检查“这个干扰项是否也满足正确项的说法”。
- ⚠ 第二轮反馈（竞赛格子不能泄露答案）：宾果格子上原本直接写着化学式（He、P₂O₅……），题目问“氦气的化学式是”时答案已经摆在格子上。老师要求改成**抽盲盒**：格子只显示编号、分值和盲盒，打开后才出题，答完再翻出化学式；10 分题每局随机放，20 分题固定在中心和角上。以后任何“选格子 / 选卡片”的竞赛，格子上的内容都要检查是否泄露题目答案。
- ⚠ 第三轮反馈（立体模型遮挡）：封面青蒿素旋转时远处的原子盖住了近处的原子。原因是透视里 z 越大越远，我却按 z 从小到大画（先画近的）；另外先画全部化学键再画原子，近处的键会被远处的原子盖住。做法：原子和“半根化学键”（原子中心到键中点）一起按深度**从远到近**排序绘制；写好后转几个角度截图，核对近处的球是否压住远处的球。
- ⚠ 第四轮反馈（旋转时键和原子“突然变化”）：按深度排序时，一根（或半根）长键只有一个深度值，转到某个角度它和某个原子的先后一交换，整根键就一下子跳到原子前面或后面；随机生成的骨架里不成键的原子比键长还近，键总是贴着别的原子穿过，问题更明显。做法：化学键从两端**球面**起止、切成 8 小段各自参与深度排序；骨架按**正四面体槽位**（键角 109.5°）生长，C/O 键长 1.5、C–H 1.1，不成键重原子间距 > 2.4、H–H > 1.7、H 与重原子 > 2.0；在一批随机骨架里挑最紧凑的；模型缩放要算上透视放大（约 1.06 × 半径 + 原子半径），保证任何角度都不压住标题和图例。纯 2D 画布能做的“伪 3D”到此为止；更复杂的立体模型按 SKILL.md 走 3D 流程。
- 自检时发现的坑：画布上逐段画化学式时，必须把 `textAlign` 设为 `left`，否则会继承前面文字的居中对齐，下标错位、整体左移；放在自定义容器里的画布要单独写 `position:absolute;inset:0;width:100%;height:100%`，否则按默认 300×150 拉伸；DOM 拖拽的卡片区要加进翻页手势的排除列表（`.tray,[data-drag],.ecard`）。

## 14. 第四单元复习（`review4/`，13 页）

- 老师的决定：风格**像素街机**；竞赛“街机待机角色，答对放技能攻击对方，打错技能卡壳摔倒”；纯度计算只出一道“提升”题、数字凑整；电解水统一用**符号表达式**；加氯化钠电解放在电解水页作提升，只用“有氯气参与 → 实验要注意什么”简短讨论；硬水软水**只复习用肥皂水区分**，不讲软化；不做课前小测。
- ⚠ **隐藏变式**（老师提出）：每道练习准备 3 道变式，平时不显示；学生答错后，老师点原题弹窗出变式巩固。我们补充：变式不计分；题目卡的红色进度格、小结页“错题回顾”可以再打开；拖卡、分类等舞台任务也配变式；翻页或关闭时弹窗自动收起。实现见 `framework.md`“题目卡与隐藏变式”。
- ⚠ **版权**：老师希望用“原神、王者”等学生喜欢的角色。这些是受版权保护的角色，不能照搬或仿制；改做同类画风的**原创**角色（红队“炎刃”火焰剑士、蓝队“澜音”水系法师），代码绘制像素画，并在课件署名里写明“原创”。以后遇到同类请求，先说明原因，再给原创替代方案。
- ⚠ **配色**：像素街机做成深紫夜空 + 霓虹网格后，老师说“街机风格色调不喜欢，换成‘浅色方格纸 + 贴纸’中的颜色搭配；布局不要拥挤，设计要合理美观、精致”。→ 改法：整套 CSS 换成浅色贴纸（纸面方格、白色贴纸面板、深蓝粗描边 + 硬投影），画布里的深色底换成白 / 浅灰，霓虹色换成珊瑚、青绿、天蓝、明黄；对战场景改成晴天（太阳、白云、薄荷山丘、湖面、砂岩擂台）。像素角色保留。**深色风格以后少推荐**；老师最稳定喜欢的是浅色贴纸。
- 自检时发现并修掉的问题：
  - 题库里的 `const C=(...)`（选择题构造函数）和公共库的颜色表 `C` 重名，整页脚本不运行 → 题库的构造函数改名 `QC`；新增全局名前先在拼好的 `index.html` 里搜一遍。
  - 换浅色后，画布里写死的白色文字、白色气体、白色角色（氢气吉祥物）全看不见 → 逐页截图找“消失”的元素，统一换成墨色描边。
  - 对战在题目答完、双方都没被打倒时仍显示“K.O.”且把败方画成倒地 → 区分“K.O.”和“判定胜”；结果列表 14 行溢出卡片 → 改成 7 列小方块。
  - 价—类图纵轴 −3、0、+2、+4、+5 等距排列，比例失真 → 按数值等比例画刻度。
  - 封面画布只占左半边，却按整页计算角色位置，角色重叠 → 按画布实际宽度摆放。
  - 微观分类放错时只标红框 → 在卡片底部写“应为混合物”。
- 技术教训：`pkill -f 某模式` 如果模式也出现在自己的命令行里，会把当前 shell 一起杀掉（退出码 144）→ 先查 PID 再按 PID 结束进程。
