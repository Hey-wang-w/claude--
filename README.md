# claude--

## 原子结构与相对原子质量 · 互动课件

`atom-structure/index.html` 是人教版九年级化学上册第三单元“原子结构 / 相对原子质量”的课堂互动课件。单个 HTML 文件，无需安装，浏览器直接打开即可（离线可用，联网时会额外加载网络字体）。

操作：← → / 空格 / 翻页笔翻页，`F` 全屏，底部“目录”可跳转任意页。

| 页 | 内容 | 互动 |
|---|---|---|
| 1 | 封面 | 可拖动视角、点击的 3D 碳原子 |
| 2 | 一滴水里的秘密 | 水滴 → 水分子 → 氧原子 → 原子核 逐级放大 |
| 3 | 原子模型的演变 | 道尔顿、汤姆孙、卢瑟福、玻尔、电子云 五种模型动画 |
| 4 | α 粒子散射实验 | 虚拟实验：发射 α 粒子、实时统计、对比汤姆孙模型、点击揭晓推论 |
| 5 | 原子的构成 | “拆开 / 组装”原子动画、粒子性质表、思考题 |
| 6 | 原子工坊 | 加减质子 / 中子 / 电子造原子，电荷账本实时计算，6 道闯关任务 |
| 7 | 原子的质量 | 碳 12 原子“切成 12 份”动画、定义 |
| 8 | 原子天平 | 用 1/12 碳 12 砝码称原子，平衡即得相对原子质量 |
| 9 | 相对原子质量的计算 | 选原子分步演算、张青莲院士 |
| 10 | 发现规律 | 填表检查、得出 Ar ≈ 质子数 + 中子数 |
| 11 | 知识闯关 | 12 道选择题，红蓝两队计分、30 秒倒计时 |
| 12 | 课堂小结 | 可点击跳转的知识结构图、下节预告 |

核外电子排布、原子结构示意图和离子放在下一节“原子结构示意图 离子”的课件中。

前 6 页只讲原子的构成，不提前出现相对原子质量；相对原子质量从第 7 页开始讲。

## 原子结构示意图与离子 · 互动课件

`ion-structure/index.html` 是第三单元课题 2 第 2 课时（原子结构示意图、离子）的课件，共 15 页（全部约 51 分钟，跳过 2 个可选页约 45 分钟），单块大屏全班互动。底部有贯穿全课的红队 / 蓝队积分，“目录”里有每页建议用时和积分调整，“特效：高 / 低”可在教室电脑卡顿时降低特效。

| 页 | 内容 | 互动 |
|---|---|---|
| 1 | 封面 | 分层旋转的钾原子，点击放出冲击波 |
| 2 | 电子怎样排队 | 1→20 号逐个加电子，层满时闪光提示，演示钾的第 19 个电子为何排到第 4 层 |
| 3 | 游戏：电子停车场 | 答题队自由放电子，另一队当裁判先判断对错，再“确认提交”；答对 +20，答错不得分并自动归位到正确排布，可“下一关”或“再练一次”（不计分）；裁判判断正确 +10 |
| 4 | 原子结构示意图 | 原子模型“压扁”成示意图的变形动画、示意图图解、读图问答 |
| 5 | 1–20 号原子图鉴（可选） | 按类别上色、隐藏电子数考考你、归纳规律 |
| 6 | 示意图找茬 | 6 张学生“作品”判对错，错误处闪烁并给出正确画法 |
| 7 | 最外层电子与性质 | 氖 / 钠 / 氯三种“性格”动画，可点击 |
| 8 | 离子的形成 | 钠 + 氯、镁 + 氧、氯 + 镁 + 氯的电子转移动画（闪电、冲击波），可逐步讲解 |
| 9 | 离子符号 | 书写规则、6 种常见离子、2Mg²⁺ 中数字的含义、原子团拓展 |
| 10 | 画一画：离子结构示意图 | 老师选择要画的离子，2 / 3 分钟倒计时，逐个揭晓并对比相同电子排布的稀有气体原子 |
| 11 | 游戏：离子符号工厂 | 按订单拼离子符号，出厂检测盖“合格 / 次品”章并指出错误，连击加分 |
| 12 | 游戏：粒子身份鉴定（可选） | 限时判断原子 / 阳离子 / 阴离子，显示质子数与电子数对比 |
| 13 | 构成物质的粒子 | 可旋转的 NaCl 晶体组装动画、物质按原子 / 分子 / 离子构成分类 |
| 14 | 闯关：击败大魔王 | 13 道与练习册同题型的新题（含提升题），答对攻击大魔王 |
| 15 | 课堂小结 | 可点击跳转的知识结构图、下节预告 |
