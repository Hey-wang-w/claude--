## 原子结构与相对原子质量 · 互动课件

`atom-structure/index.html` 是人教版九年级化学上册第三单元“原子结构 / 相对原子质量”的课堂互动课件。单个 HTML 文件，无需安装，浏览器直接打开即可（离线可用，联网时会额外加载网络字体）。

操作：← → / 空格 / 翻页笔翻页，`F` 全屏，底部“目录”可跳转任意页。

| 页 | 内容 | 互动 |
|---|---|---|
| 1 | 封面 | 可拖动视角、点击的 3D 碳原子 |
| 2 | 一滴水里的秘密 | 水滴 → 水分子 → 氧原子 → 原子核 逐级放大 |
| 3 | 原子模型的演变 | 道尔顿、汤姆孙、卢瑟福、玻尔、电子云 五种模型动画 |
| 4 | α 粒子散射实验 | 虚拟实验：发射 α 粒子、实时统计、对比汤姆孙模型、点击揭晓推论 |
| 5 | 原子的构成 | “拆开 / 组装”原子动画、粒子性质表、思考题 |
| 6 | 原子工坊 | 加减质子 / 中子 / 电子造原子，自动生成结构示意图，6 道闯关任务 |
| 7 | 核外电子排布 | 1–18 号元素结构示意图、示意图图解、“考考你”遮挡模式 |
| 8 | 最外层电子与化学性质 | 钠与氯电子转移动画（离子拓展） |
| 9 | 原子的质量 | 碳 12 原子“切成 12 份”动画、定义 |
| 10 | 原子天平 | 用 1/12 碳 12 砝码称原子，平衡即得相对原子质量 |
| 11 | 相对原子质量的计算 | 选原子分步演算、张青莲院士 |
| 12 | 发现规律 | 填表检查、得出 Ar ≈ 质子数 + 中子数 |
| 13 | 知识闯关 | 12 道选择题，红蓝两队计分、30 秒倒计时 |
| 14 | 课堂小结 | 可点击跳转的知识结构图 |
